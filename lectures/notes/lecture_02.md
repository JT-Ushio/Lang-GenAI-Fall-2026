# 第二讲：模态表示与跨模态协同

建议 45–55 分钟：导入 3 分钟、灰度图 7 分钟、RGB 9 分钟、音频试听与采样 12 分钟、视频 9 分钟、点云 7 分钟、回顾 3 分钟。可根据试听和讨论时间压缩；第二部分安排见文末。

## 操作

从 `lectures` 运行 `python3 execute.py -m lecture_02`；进入 `trace-viewer` 执行 `npm run dev -- --host 127.0.0.1 --port 4173`，打开 `http://127.0.0.1:4173/?trace=var/traces/lecture_02.json&step=1&animate=1`。若已有该端口的服务器，不必重复启动，直接打开链接。`R` 查看源码、`A` 切换逐步模式。print 输出在编译时产生，不是浏览器现场执行。

试听用浏览器原生音频控件，手动播放，无自动播放；切换步骤会暂停，因此试听时停留在当前步骤。比较 /s/ 与 /ʃ/ 和扫频末段，保持音量适中且相同。16 kHz 仍能覆盖这个扫频的主要频率范围；8 kHz 版本会滤去超过其带宽的高频部分。不要声称每个人都一定能听出差别。

## 教学边界

- 数字是 sklearn 8×8 的 digits，标签为 3，不是 MNIST；本节只认识输入与标签，没有训练识别器。
- 灰度原始范围 0–16，用 uint8 保存不意味着已经归一化到 0–255。
- RGB 显示尺寸、像素尺寸、PPI、清晰度有区别；通道图用灰度可视化强度。
- N×C 是本课约定，不是所有库的统一轴顺序。48/16/8 kHz 的位深均为 PCM16。
- MP4 是容器；数组是实际解码得到。音频可能有 AAC 填充，不能仅凭解码样本数把播放时长算得过于绝对。
- 网格与点云各自从同一立方体直接构造，未展示重建算法。点的顺序通常没有图像栅格那样固定的邻接意义。
- 最后自查答案：只把采样率标签减半会使播放时长约翻倍、音高约降一个八度；正确降采样同时改变采样点序列与采样率，保持原时长和音高。

原始数据与重建方法见 `images/lecture_02/README.md`。

## 第二部分：跨模态协同任务（新增）

建议约 35–40 分钟：四类任务概览 3 分钟、图文 8 分钟、语音 12 分钟、视频 7 分钟、点云 7 分钟、小结 3 分钟。与第一部分配合，按 90 分钟课堂选择展开深度。

第一部分已将主要设问改为直接解释，并在术语首次出现时补充中文含义。第二部分任务例子是输入／输出设计，不是已调用在线模型的结果。点云拉伸例子运行真实 NumPy 代码。

重点区分：
- 检索找已有内容；生成产生新内容；编辑有原内容与保留约束。
- 全双工是双向同时传递／处理；轮流对话不一定意味着网络半双工。流式、可打断、全双工不能互相等同。
- 图文：语义和位置对应；语音：内容与话轮时机；视频：时间定位与跨帧一致性；点云：坐标系与几何约束。
- 3D 资产不一定是点云；文本生成立体感图像不等于生成三维几何。代码只演示几何变换，没有声称理解了自然语言。

## 音频扩展：多声道与空间音频

新增约 8–10 分钟，可按课堂时间选讲空间音频。两个播放器比较立体声与单声道，建议佩戴耳机；教室外放的左右定位受座位影响。示例只做声道音量平衡，没有模拟三维声场。先解释 N×C 与交错 PCM，再讲 5.1、5.1.2 布局，最后区分基于声道、基于对象、双耳渲染与头部追踪。各术语独立一行。
