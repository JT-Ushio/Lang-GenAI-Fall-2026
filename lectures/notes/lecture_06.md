# 第六讲备课说明：多模态理解与生成统一

主文件为 `lectures/lecture_06.py`。本讲承接第四讲的图像理解与第五讲的文字条件视觉生成，核心是理解与生成如何进入共同模型、如何利用交错图文上下文，以及如何进一步组成多模态智能体的反馈循环。图像编辑是贯穿案例，ControlNet、遮罩强度与参考图适配不再构成主线。

中文正文面向外语＋计算机双学位本科生。遵循学生课件直接讲知识的要求，不展示教学目标、授课对象、课时分配、设计参考或下讲预告。教学安排、实现边界和操作方法集中放在本文件。组织方式继续参考 CS336 的短函数、输入输出接口、图示与可执行代码穿插，不翻译或复制其讲义内容。

## 关键技术口径

- 条件生成本来就有语言语义表示。这里不能说此前模型“不理解任何语言”，而应说明它与统一理解生成、长期上下文、行动反馈的区别。
- **统一模型不自动等于智能体**。模型统一是能力／架构／训练层的属性；智能体还要有目标、状态、动作执行、观察、验收和停止。多个专用模型也可以被组织成智能体。
- **统一不要求一切完全相同**。Janus 可解耦视觉编码，BAGEL 可按模态使用不同专家参数，生成可以使用自回归、离散掩码或连续流。
- **语言说明不等于任务完成证据**。所谓“先理解再生成”不要求输出冗长推理，也不表示一段正确说明能证明生成图正确。结果需要独立观察与验收。
- **图像编辑不自动属于每个统一模型的现成能力**。Janus-Pro 的理解／文生图接口不能直接推广成任意编辑；BAGEL、Show-o 对应的编辑任务和生成机制需分别查论文与实现。

## 实际训练的微型统一模型

代码在 `demos/lecture_06_unified.py`。

- **数据**：4×4 图像，背景、红、绿、蓝四种调色板颜色；左／右色块分别可取三种颜色，共九种图像。固定调色板将每个像素映射到一个图像编号，不是训练得到的 VQ 编码器。
- **词表**：18 个词元，含任务、边界、左右、颜色词和四个视觉编号。文字颜色词与视觉颜色编号使用不同 ID。下拉选项直接映射到固定符号，未实现开放中文分词或自由指令理解。
- **任务**：九个看图描述、九个文生图、54 个编辑样本（含已经满足颜色要求的情况），共 72 个样本。三个任务读取同一套模型参数。
- **结构**：宽度 48、两层、四头、前馈宽度 96、零 dropout、最大位置 64，共 42,834 参数。统一词元嵌入、完全因果 Transformer 和 18 类输出头。它是最小自回归统一模型，不是 Janus／Show-o／BAGEL 的等比例复现。
- **优化**：AdamW，学习率 0.003、weight decay 0.01、梯度裁剪 1.0，更新 1,000 次；每次从每种任务有放回抽九个样本，三种任务损失等权平均。训练 RNG 固定，CPU 单线程；运行后恢复线程数。
- **监督**：将序列右移一位，条件前缀和补齐位置标签为 -100；第一个答案由输入前缀的最后一个位置预测。文字答案监督 5 个词元；图像答案监督 19 个词元（图像起止标记、16 个像素编号、EOS）。
- **生成**：从条件开始逐步接回模型自己的 argmax 输出，遇 EOS 或达到最大长度停止，不在推理时喂标准目标词元，不使用目标像素覆盖网络输出。严格解析视觉编号和边界格式，格式错误就报告失败。
- **评估边界**：全部 72 个样本都用于训练。自由生成精确匹配衡量拟合；没有独立测试集，不证明未见图像、开放自然语言或真实照片泛化。报告提供同一模型权重的 SHA-256。
- **共享梯度**：分别从理解与生成损失计算同一主干线性层权重的梯度，断言都非零。梯度存在证明两任务参与更新，不证明正迁移。报告中的梯度小实验使用独立随机初始化；课件代码还对训练后模型现场计算两类梯度，数值无需相同。

## 智能体演示的分工

目标固定为左红变绿、右侧保持最初蓝色。`caption_image()` 与 `edit_image()` 调用同一个训练后网络；规划是明确的规则策略，像素验收是独立的确定性程序。

1. 正常情形：观察当前图，选择左侧变绿，生成新图，验收成功，一步结束。
2. 故障情形：第一次执行时把动作对象左右交换，网络按错误工具参数生成右绿的新图；下一次神经观察读出左红右绿，规则策略先恢复右蓝，再将左侧改绿，共三步。
3. 预算不足：沿用同一故障但最多两步，只恢复到左红右蓝，目标尚未完成，必须返回“预算耗尽，未完成”。

故障由实验注入，不当作真实模型自然错误率。规划与停止规则不是语言模型学出的能力；自然语言界面只是固定词元的中文显示。历史保存在控制器中，神经模型每步读取当前图与任务词元；未把完整图文历史全部输入微型模型。该分工同时展示“共享模型的能力”和“智能体控制逻辑”，避免把二者混为一谈。

原图用于独立检查右侧保留约束，完整目标图用于最后验收。控制器不接受模型自己的“已经完成”声明；输出格式不合法时停止并报告错误。真实开放任务无法总用像素精确比较，需要可靠工具、标注或人工评价。

## 三个交互视图

独立入口 `images/lecture_06/unified/index.html`，无外部 JS 或 CDN。

- **图文序列**：切换理解／生成／编辑，显示已知前缀、标准目标和右移后的损失标签；区分视觉词元、文字词元和 -100。
- **同一模型**：切换原图两侧颜色、任务、编辑对象和目标颜色，查看 Python 保存的真实逐步生成输出及共享模型 SHA 前缀。文生图时左侧图仅是文字含义示意，不冒充模型的图像输入。
- **智能体闭环**：逐步播放正常、首次错位、预算不足三种轨迹，对照计划参数与实际执行参数，检查目标与保留项分别是否通过。预算不足的终点明确显示未完成。

## 模型与图示的具体来源

核对日期 2026-10-26；使用经典公开案例讲机制，不宣称是最新排名。全部示意图为本课程原创，结果图来自本地小模型，没有把规则图形或随机权重冒充大模型效果。

- [Janus 论文](https://arxiv.org/abs/2410.13848)、[Janus 作者实现](https://github.com/deepseek-ai/Janus)：解耦视觉理解／生成编码，共享 Transformer。Janus-Pro-7B 配置为理解 1024→4096、视觉头 16384 类、文字词表 102400；作者生成代码默认 384 分辨率、16 倍视觉下采样、576 个编号，生成 VQ 嵌入 8 维。配置固定 revision、URL 和 SHA-256 见 `demos/lecture_06_configs/unified_sources.json`，只保存 JSON、不含权重。meta 代码简化投影为线性层，只验证维度，不复现完整两层连接器。
- [Show-o 论文](https://arxiv.org/abs/2408.12528)、[论文方法正文](https://arxiv.org/html/2408.12528v7)：自回归文字与掩码视觉预测；经典离散配置为 256×256→16×16 编号，码本 8192。六位置注意力小例子只展示已知条件块内双向与块间因果，不能作为完整 Show-o／BAGEL 训练掩码直接使用。
- [BAGEL 论文](https://arxiv.org/abs/2505.14683)、[架构与注意力](https://arxiv.org/html/2505.14683v3#S2)、[作者实现](https://github.com/ByteDance-Seed/Bagel)：ViT 语义特征与 VAE 连续潜变量、MoT、整流流生成和交错上下文。512×512 是形状例子：VAE 16×64×64，再 2×2 patch 得 1024 个 64 维潜块，之后投影到主干宽度。完整模型使用可变尺寸，不把示例分辨率说成固定上限；不把 MoT 误写成所有参数共享，也不把其完整干净／加噪视觉块隔离简化成纯三角掩码。
- [ReAct](https://arxiv.org/abs/2210.03629)：任务中交替组织推理、动作和观察；用于解释系统闭环，不据此把单次生图直接称为智能体。
- [CS336 lectures](https://github.com/stanford-cs336/lectures)：教学组织方式参考，未将其作为上述模型架构的技术来源。

## 验收记录

本地运行的训练样本自由生成精确匹配：理解 9/9、生成 9/9、编辑 54/54。三个任务交叉熵均从约 3 降至 0.001 以下；这些均为训练域结果。正常一步完成、注入错位后三步完成、两步预算耗尽未完成的断言通过。报告中的随机初始化共享层梯度范数约为 0.4471／0.2978，均非零。

主课件编译为 276 个步骤，无 stderr；17 张 SVG 已渲染并检查排版。共享主干的因果性测试通过：改变未来词元不改变前缀输出；72 个样本的监督右移位置、九个图像编码往返、非法输出拒绝与配置 SHA-256 均已检查。DOM／canvas 桩检查覆盖全部 72 个模型结果、任务切换、监督位置、一步成功、三步恢复、两步失败与复位。

浏览器中实际操作了三个内嵌视图：编辑前缀 23 词元、监督 19 个输出；看图回答“左红，右蓝”；编辑结果精确匹配；首步错位时目标与保留均未通过，第三步完成；两步情形显示“预算耗尽，未完成”。交互步骤没有变量浮窗遮挡。静态网站构建通过，保留框架原有的大包提示；资源与编译源的校验结果通过。以上不等于运行 Janus、Show-o 或 BAGEL 预训练大模型的质量测试。
