# 第五讲备课说明：从噪声到图像

主文件 `lectures/lecture_05.py`。面向外语＋计算机双学位本科生，按 45 分钟 × 2 课时安排，从第三讲 CLIP、第四讲生成式 VLM 转入文字条件下的图像生成。图示为本课程原创 SVG；生成示例来自本地训练的微型模型，不冒充 Stable Diffusion 的实测输出。

## 交互实验室

`images/lecture_05/diffusion-lab/index.html` 可独立打开；使用本地 JS，无 CDN：

1. **加噪**：固定教师绘制的 32×32 RGB 原图与一份噪声，拖动 t 查看系数与真实像素合成。t=0 是第一次加噪后的数组索引，干净图单列。不同 t 的对照不是一条逐次采样噪声的马尔可夫轨迹；显示时才裁剪。
2. **采样**：播放 Python 保存的真实微型模型采样状态，可在横条／竖条之间切换；相同初始噪声、相同后续随机数序列。浏览器不训练、不倒放加噪动画。
3. **架构**：点击 SD 1.5 模块，切换 B=1/2 和 CFG 批量合并，查看 B 与 2B 的区别。这是结构解释，不执行 SD 权重推理。

宽图最大 760 px，并受视口约束；SD 总览附独立大图入口，适合课堂投影或单独放大。

## 可执行演示与验证边界

- **加噪与已知噪声反算**：RGB 数组、固定种子，直接执行扩散边缘分布公式，断言反算最大误差低于 1e-5。这只是数值一致性，不是训练好的去噪器。
- **真实训练**：六张 8×8 条纹模板，两种类别，39,280 参数的 MLP；输入 64 像素＋32 维时间＋16 维条件。Adam 学习率 0.0015，批量 128，4,000 次更新；15% 条件替换为空条件编号 2。代码实际计算噪声 MSE、反向传播与参数更新。
- **受限评估**：固定评估噪声、t、模板抽样；模板仍来自训练集合。起始和末尾 MSE 及 64 个新噪声生成样本的方向匹配写入报告。方向规则比较行／列均值方差；不验证位置、自然图像审美、未见模板泛化或自然语言语义。没有独立干净图像测试集。
- **实际生成**：100 步 DDPM，线性 β=0.0001…0.15，最终 ᾱ 约 0.000366。使用预测 x₀ 的裁剪和固定后验方差，最后一步不加随机项。种子重复一致、两条件初始噪声相同、MSE 下降和受限方向匹配均有运行断言。采样图来自网络，不是倒放数据破坏过程。
- **SD 形状**：公开配置＋meta 张量；实际执行 Embedding、Conv2d、池化、上采样与拼接的形状计算，未计算的 Transformer／VAE 用接口占位。U-Net 通路已简化，不是完整模块逐层复现，也不验证预训练权重数值。
- **交叉注意力**：随机特征真实执行 QKᵀ、softmax、加权 V，断言每行权重和为 1；随机结果没有语言语义。
- **CFG 小算例**：实际张量组合，验证 s=1 返回条件预测；完整微型模型也实际使用两次前向和 CFG 采样。

固定种子可复现同一环境中的记录；不同 PyTorch 版本／平台仍可能产生浮点差异。报告保留实际运行结果，不把某次小模型的成功推广到所有条件生成模型。

初版本地验收（2026-10-19）：编译得到 365 个步骤，无 stderr；加噪公式反算最大误差约 1.19e-7；固定噪声评估 MSE 从 0.9962 降至 0.1019；64 张新噪声生成样本的受限方向匹配为 100%。16 张 SVG 已渲染检查，修复了中文字体下的下标缺字和架构图文字框高度。资源路径、配置文件校验和、Markdown 加粗解析及交互脚本的滑块／采样记录／批量维度逻辑均通过检查。交互脚本逻辑使用 DOM 与 canvas 桩验证，不等于浏览器验收；初版浏览器自动打开连续两次因权限审核超时未完成。静态网站构建通过，保留原有的大包体积提示。加入视频讲解图后的新步骤数以重新生成的 trace 为准。

## Stable Diffusion 1.5 技术口径

- 只讲经典 SD 1.5、512×512 情形，不能把这些维度泛化到 SDXL、SD3 或所有扩散模型。
- 分词器 `[B,77]`，文本隐藏状态 `[B,77,768]`；77 包含特殊与补齐位置。使用序列特征，不是第三讲的整句检索投影向量。纯文生图推理不必调用 CLIP 图像编码器。
- RGB `[B,3,512,512]`，VAE 后验参数 `[B,8,64,64]` 拆成均值／对数方差各 4 通道；潜变量 `[B,4,64,64]`。
- 每边空间缩小 8 倍；元素数量比为 48，不是文件压缩率。0.18215 是另一个幅值缩放，来自原始 CompVis 配置，老 Diffusers VAE 配置 JSON 未列此字段；解码前除回去。
- U-Net 层级通道 320／640／1280／1280，代表分辨率 64／32／16／8；上行图为相同空间层级的代表性形状，省略块内多次残差、拼接和注意力。不能把图中一框等同于某个库的完整 up block 最后输出。
- 64×64 层级的视觉特征可展为 4096 个位置、320 维；文本 768 维先投影到交互宽度。图示省略多头，4096×77 是每组查询与键的分数表。
- 时间嵌入 320→1280；它告知噪声水平，与文本位置编码不同。
- CFG 使用常见 Diffusers 约定 `eps_u + s*(eps_c-eps_u)`；论文／其他实现的权重定义可能平移，比较时应先看公式。两条分支共享参数，空提示特征不为零。批量合并时 `[2B,4,64,64]` 与 `[2B,77,768]`，组合后回到 B。
- 公开调度器快照为 PNDM，1,000 时间索引，scaled_linear，β 端点 0.00085／0.012。课堂 RGB 前向图用 1,000 步线性 0.0001…0.02；MLP 用 100 步线性 0.0001…0.15。三者分开标注。
- DDIM 的 η=0 确定性仍依赖给定初始噪声与条件，不能称为“不需要随机种子”。训练 T 与推理 K 不同，不可只删循环中的任意步。

## 一手来源
